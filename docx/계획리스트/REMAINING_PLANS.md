# 남은 게임 개발 계획

> 각주: 이 남은 계획 목록은 2026-10-24 17:30 KST에 작성했습니다.

## 우선순위 기준

- 기능 검증, 조작감 개선, 버그 수정을 아트·음성·애니메이션보다 먼저 진행합니다.
- 수치나 보정은 실제 플레이 결과와 공정성을 검증한 뒤 조정합니다.
- 필요한 수치와 동작이 미정인 기능은 임의로 확정하지 않고 사양 결정을 먼저 진행합니다.

## 최우선 1: 능력치 보상의 실제 게임 적용 검증

### 목표

이동 속도, 공격 사거리, 공격 속도, 최대 체력, 피해량 강화가 계산 함수뿐 아니라 실제 플레이에서 자연스럽게 적용되는지 검증합니다.

### 현재 상태

- 세 개의 레벨업 카드는 각각 무기 60%, 능력치 40% 확률로 생성됩니다.
- 다섯 능력치는 강화 횟수당 기본값의 5%를 합연산합니다.
- 계산, 최대 체력, 확률 경계, 투사체 사거리·피해량 테스트가 있습니다.
- `GameScene`의 실제 이동과 공격 타이머 연결, 재시작 초기화는 추가 통합 검증이 필요합니다.

### 구현 및 검증 단계

1. 보상 선택→강화 횟수 저장→실제 이동·타이머·타깃 탐색·공격 판정·HUD 사용→재시작 초기화 경로를 테스트 가능한 단위로 정리합니다.
2. 기본값, 1회 105%, 4회 120%, 재시작 후 100%를 각각 자동 테스트합니다.
3. 기본공격 기준으로 1회 강화 후 사거리 420px, 피해 10.5, 공격 간격 `0.75초 ÷ 1.05`를 확인합니다.
4. 최대 체력은 100→105, 현재 체력은 +5가 되며 HUD 표시와 체력 바가 일치하는지 확인합니다.
5. Phaser 브라우저에서 강화 전후의 WASD 이동, 발사 주기, 타깃 획득 거리, 투사체 소멸 지점, 피해량을 비교합니다.
6. 공격 타이머 중복·정지, 입력 지연·떨림, 사거리 밖 공격, 재시작 후 강화 효과 잔류가 없는지 확인합니다.

### 완료 기준

- 자동 테스트와 빌드가 통과합니다.
- 계산 테스트와 실제 게임 상태 연결 테스트가 모두 통과합니다.
- 브라우저 검증을 수행했거나, 실행할 수 없는 이유와 미검증 항목을 명시합니다.

## 최우선 2: 플레이어 무기 4~5종 확장

### 목표

현재 운용 가능한 3종의 무기를 4~5종으로 늘리고, 신규 획득·중복 강화·무기 창고·자동 조준에 연결합니다.

### 선행 결정

- 추가할 1~2종의 무기 콘셉트와 공격 방식을 확정합니다.
- 피해량, 공격 간격, 사거리, 투사체 수·속도, 무기별 강화율, 5레벨 특전을 확정합니다.
- 임시 아이템 A가 계속 창고 한 칸을 사용할지 결정합니다.

### 구현 및 검증 단계

1. 승인된 사양을 무기 정의와 독립 공격 계산에 추가합니다.
2. 기본값, 반복 강화, 사거리 종료, 충돌, 5레벨 특전을 무기별로 자동 테스트합니다.
3. 신규 무기를 레벨업 보상 60% 풀, 무기 창고, HUD, 자동 조준에 연결합니다.
4. 미획득 무기는 신규 획득되고 획득한 무기는 다시 등장해 레벨과 고유 특성을 강화하게 합니다.
5. 창고 한도 5개, 기본공격 분리, 레이더 내 최근접 적 조준이 유지되는지 회귀 검증합니다.
6. Phaser 브라우저에서 무기별 발사, 충돌, 사거리, 피해, 중복 강화, 창고 표시를 확인합니다.

### 완료 기준

- 플레이어가 기본공격 외에 4~5종의 무기 조합을 정상적으로 운용합니다.
- 신규 획득과 중복 강화가 같은 보상 흐름에서 정상 동작합니다.
- 자동 테스트, 빌드, 브라우저 회귀 검증 결과를 보고합니다.
