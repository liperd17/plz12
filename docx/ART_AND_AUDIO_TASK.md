# 외부 AI 작업 요청: 도트 아트 및 오디오

이 문서는 추후 다른 AI가 수행할 아트·오디오 작업의 의뢰서입니다. 지금은 에셋 제작이나 게임 코드 변경을 하지 않습니다.

## 게임 콘셉트
- 괴물 식재료로부터 살아남는 서바이버 시리즈 스타일의 2D 탑다운 로그라이크 액션 게임입니다.
- 현재 게임의 플레이 방식과 전투 규칙을 유지하면서 시각·음향 표현을 추가합니다.

## 공통 아트 방향
- 모든 게임 아트는 복고풍 2D 픽셀 도트 스타일로 제작합니다.
- 게임 전체에서 공유하는 고정 팔레트는 정확히 8개의 불투명 색상으로 구성합니다. 투명 픽셀은 색상 수에 포함하지 않습니다.
- 작업을 시작하기 전에 8색 팔레트의 색상값과 용도를 제안하고 사용자 승인을 받아 확정합니다.
- 팔레트가 확정된 뒤에는 별도 요청이 없는 한 모든 스프라이트와 타일에 확정된 8색만 사용합니다. 새 색상, 그라데이션, 안티앨리어싱을 임의로 추가하지 않습니다.
- 기존 게임 코드와 에셋 구조를 먼저 확인한 뒤, 프로젝트에서 효율적으로 사용할 수 있는 크기·시트 구성·파일 형식을 제안합니다.
- 외부 게임의 캐릭터·이미지·음원을 복제하지 말고 게임 콘셉트에 맞는 오리지널 에셋을 제작합니다.

## 제작할 아트

### 플레이어 캐릭터
- 선택 가능한 플레이어 캐릭터 2종을 요리사 콘셉트로 표현합니다.
- 두 캐릭터 모두 요리사 복장과 요리사 모자를 착용합니다.
- 기존 초록 모험가는 초록색 표현을 유지하면서 요리사 복장으로 디자인합니다.
- 빨간 모험가는 빨간색 표현을 유지하면서 요리사 복장으로 디자인합니다.
- 작은 게임 화면에서도 색상과 실루엣만으로 두 캐릭터를 쉽게 구분할 수 있게 합니다.

### 무기와 공격 표현
- 플레이어가 사용하는 무기는 주방 식기로 표현합니다. 예: 식칼, 거품기.
- 현재 게임에 있는 기본 공격, 연사 공격, 참격 공격의 시각 효과와 무기 표현을 먼저 확인하고 각 기능에 어울리는 주방 도구를 제안합니다.
- 무기 표현은 기존 공격 판정과 동작을 오해하게 만들지 않도록 합니다. 아트 작업을 이유로 공격 방식이나 밸런스 수치를 변경하지 않습니다.

### 맵 타일
- 맵 바닥은 격자무늬가 보이는 회색 돌 기반의 주방 바닥으로 표현합니다.
- 반복 배치해도 이음새가 두드러지지 않는 타일을 우선하며, 플레이어·몬스터·투사체가 배경에서 잘 식별되도록 명도와 대비를 확보합니다.

### 몬스터
- 일반 박쥐 종류는 괴물 토마토로 표현합니다.
- 파란 박쥐 종류는 괴물 물고기로 표현합니다.
- 녹색 박쥐 종류는 괴물 돼지로 표현합니다.
- 현재 종류별 크기 차이를 유지합니다. 특히 녹색 몬스터는 일반 몬스터보다 큰 실루엣으로 표현합니다.
- 각 종류는 지정된 대표 색상과 실루엣으로 쉽게 식별할 수 있게 하며, 기존 이동·체력·생성 비율은 변경하지 않습니다.

## 오디오 작업
- 게임의 괴물 식재료·주방 콘셉트와 서바이버 장르에 어울리는 오리지널 배경음악과 효과음을 제안·제작합니다.
- 배경음악은 장시간 반복 재생에 적합하도록 자연스럽게 루프되게 합니다.
- 효과음은 기존 게임 이벤트를 확인한 뒤 필요한 항목을 목록으로 제안합니다. 예: 기본 공격·무기별 공격, 몬스터 피격·처치, 플레이어 피격, 레벨업, 메뉴 선택.
- 효과음은 짧고 명확하게 만들고, 반복 재생 시 피로감을 줄이며 배경음악을 가리지 않도록 음량을 조절합니다.
- 오디오 에셋의 파일 형식·샘플레이트·용량은 프로젝트에서 지원하는 형식을 확인하고 제안합니다.

## 구현 및 검수 기준
- 사용자에게 먼저 8색 팔레트 제안과 에셋 목록·규격을 제시하고 승인을 받습니다.
- 승인 전에는 팔레트에 의존하는 최종 에셋 제작과 게임 코드 통합을 시작하지 않습니다.
- 승인 후 에셋을 프로젝트에 추가하고, 기존 코드 구조를 따르는 최소 범위로 로드·표시·재생을 연결합니다.
- 게임 규칙, 캐릭터 능력치, 몬스터 능력치, 공격 판정, 생성 비율을 변경하지 않습니다.
- 새 에셋 적용 뒤 빌드와 기존 자동 테스트를 실행하고, 화면에서 캐릭터·몬스터·맵의 식별성과 오디오 루프·효과음 재생을 확인합니다.
- 최종 보고에 확정된 팔레트, 추가된 파일, 적용한 게임 이벤트, 실행한 검증 결과를 정리합니다.
