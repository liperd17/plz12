# Implement Plan

작성된 구현 계획을 바탕으로 실제 코드를 작성한다.

## 작업 절차

1. AGENTS.md와 구현 계획을 확인한다.
2. 계획에 작성된 작업을 순서대로 구현한다.
3. 각 단계가 끝나면 정상적으로 구현되었는지 확인한다.
4. 문제가 발견되면 원인을 확인하고 수정한다.
5. 모든 단계가 끝나면 전체 결과를 확인한다.

## 작업 결과 형식

### 구현 완료 내용
어떤 기능을 구현했는지 설명한다.

### 검증 결과
어떤 방법으로 확인했고 결과가 어땠는지 설명한다.

### 남은 문제
해결하지 못한 문제나 추가 확인이 필요한 사항을 설명한다.

## 규칙

- 기존 계획의 범위 안에서 작업한다.
- 계획에 없는 기능은 임의로 추가하지 않는다.
- 기존 기능이 정상적으로 유지되도록 한다.
- 계획을 변경해야 한다면 이유를 설명하고 사용자에게 확인한다.
- 별도 요청 없이 Git Commit을 수행하지 않는다.
