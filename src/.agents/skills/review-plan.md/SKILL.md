# Review Plan

작성된 구현 계획을 검토하고 개선할 부분을 제안한다.

## 작업 절차

1. 검토할 계획서와 AGENTS.md를 확인한다.
2. 계획과 관련된 기존 코드를 확인한다.
3. 요구사항이 계획에 빠짐없이 반영되었는지 검토한다.
4. 기존 기능에 미치는 영향과 예상 위험을 검토한다.
5. 구현 단계와 검증 방법이 적절한지 확인한다.
6. 발견한 문제와 개선안을 정리한다.

## 검토 결과 형식

### 종합 평가
계획의 전반적인 상태를 간단히 설명한다.

### 발견한 문제
- 문제 내용
- 문제가 발생할 수 있는 이유
- 중요도: 높음 / 보통 / 낮음

### 개선 제안
발견한 문제를 어떻게 해결하면 좋을지 설명한다.

### 최종 의견
계획을 그대로 진행해도 되는지,
수정이 필요한지 판단한다.

## 규칙

- 계획 검토 단계에서는 코드를 수정하지 않는다.
- 검토 대상 계획서도 임의로 수정하지 않는다.
- 실제 코드와 요구사항에 근거해 검토한다.
- 근거 없는 문제를 만들어내지 않는다.
- 문제가 없다면 문제가 없다고 명확하게 설명한다.
- 검토가 끝나면 사용자의 다음 지시를 기다린다.
